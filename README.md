# Game Translate Pro

Android app project for translating visible game text and player chat into Persian.

## Planned
- On-screen OCR using Android MediaProjection consent and ML Kit Text Recognition.
- Persian rendering of common Finglish chat phrases.
- User-controlled floating translation panel.
- Screen recording through Android's official MediaProjection permission flow.
- Downloads screen for recordings saved by the app.

## Current status
Initial Android/Jetpack Compose scaffold. OCR capture pipeline, overlay, recording controls, downloads UI, and translation engine are not implemented yet.
