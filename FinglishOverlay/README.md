# Finglish Overlay — Android

برنامه نمونه اندروید برای تشخیص نوشته‌های روی صفحه با ML Kit و نمایش ترجمه در پنجره شناور.

## وضعیت و محدودیت‌ها
- OCR با ML Kit Text Recognition (مدل لاتین) روی خود دستگاه انجام می‌شود.
- ترجمه ترکیبی: ابتدا تلاش آنلاین از MyMemory (en → fa)، و در صورت خطا یا عدم دسترسی، خروجی آفلاین واژه‌نامه/تبدیل نویسه‌ای نمایش داده می‌شود.
- فینگلیش املای استاندارد ندارد؛ خروجی آفلاین این نسخه برای کلمات رایج مناسب‌تر است.
- سرویس آنلاین عمومی ممکن است کیفیت یا محدودیت نرخ داشته باشد. متن بازی به سرویس آنلاین ارسال می‌شود.
- کادر در نسخه اولیه بالای صفحه ثابت است؛ جابه‌جایی و انتخاب ناحیه OCR هنوز پیاده‌سازی نشده است.
- MediaProjection با تأیید صریح کاربر فعال می‌شود و بعضی بازی‌ها ممکن است تصویر را مسدود کنند.

## نیازمندی‌ها
Android Studio، JDK 17، Android SDK 35 و Android 8.0 یا بالاتر.

## اجرا
پوشه FinglishOverlay را در Android Studio باز کنید، Gradle Sync را کامل کنید، برنامه را اجرا کنید و مجوزهای نمایش روی برنامه‌های دیگر و ضبط صفحه را فقط در صورت تمایل فعال کنید.

## حریم خصوصی
تصویر صفحه برای OCR روی دستگاه پردازش می‌شود؛ متن استخراج‌شده برای تلاش ترجمه آنلاین به MyMemory فرستاده می‌شود. برای استفاده آفلاین، بخش آنلاین را غیرفعال یا جایگزین کنید. این نمونه هنوز روی دستگاه واقعی تست و تأیید نشده است.
